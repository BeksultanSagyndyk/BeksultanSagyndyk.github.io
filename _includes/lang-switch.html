{% comment %} ENG / ҚАЗ switcher — a pill toggle with a sliding thumb, top-right of the content column. Pairing is by `ref:` in the front matter: the English page and its Kazakh twin carry the same ref. Kazakh files carry `lang: kk` (set automatically for the kk_posts collection in _config.yml); English files need no lang at all. Pages with no ref (materials, tags) show ENG as active and ҚАЗ greyed out, so the widget sits in the same place on every page. To add a translation: create the Kazakh file with the same `ref:` — the link below starts working on its own, no edit needed here. The thumb sits under whichever option matches data-lang. Clicking the other option flips data-lang first so the thumb slides, then navigates once the transition has played (see the script at the bottom). With JS off, or with prefers-reduced-motion, the links navigate immediately as plain links. {% endcomment %} {% assign cur = page.lang | default: 'en' %} {% if page.ref %} {% assign candidates = site.posts | concat: site.kk_posts | concat: site.pages | where: "ref", page.ref %} {% if cur == 'kk' %} {% assign alt = candidates | where_exp: "p", "p.lang != 'kk'" | first %} {% else %} {% assign alt = candidates | where_exp: "p", "p.lang == 'kk'" | first %} {% endif %} {% endif %}
